## 1. 产品定义

- **一句话描述**：把第三方中转站 / 自有 API Key 一键植入 Codex CLI、Codex Desktop、WorkBuddy 三套 AI 开发工具的 C 端免安装桌面配置器——双击直接运行，粘贴 Key 后一键完成配置。
- **产品定位（用户修订 2026-09-24）**：C 端消费级工具。**双击即用**（Windows 单 exe / macOS .app，双击直接运行、零依赖、零安装）；**一键配置**（唯一必填：API Key + 中转地址，模型拉取/过滤/测速/备份/写入/验证自动串成一条流水线）。
- **目标用户**：同时使用多款 AI 开发工具、持有第三方中转站或自有 API Key 的中文开发者（主画像），多机便携用户与教程作者为次画像。
- **核心问题**：三套工具配置格式完全不同（config.toml+auth.json / models.json），手动编辑踩坑多（TOML 字段错一处 CLI 起不来、URL 漏 /v1、模型 ID 抄错），Codex Desktop 解锁第三方 Key 需要跑命令行 ASAR 补丁脚本，且没有任何现成工具同时覆盖这三个目标。

## 2. 竞品分析（3 直接 + 3 替代）

| 竞品 | 定位 | 优势 | 劣势（差评驱动） |
|------|------|------|------------------|
| cc-switch（~89k★） | Tauri GUI，7 款 CLI 工具 Provider 切换 | 功能全、预设 50+、托盘秒切 | 本地代理是最大故障点；覆盖用户手动修复；不支持 WorkBuddy；安装包非便携；Key 集中存储有安全顾虑 |
| cc-switch-cli | Rust CLI 切换器，8 工具 | 单二进制、有远程模型拉取 | 无 GUI；不支持 WorkBuddy/Desktop 补丁 |
| ccman | Node CLI+Desktop | 零破坏写入、备份回滚完整 | 依赖 Node ≥18；无模型拉取；不支持 WorkBuddy |
| Claude Code Router | 本地常驻路由 | 任务级智能路由 | 单目标、常驻服务、配置复杂 |
| new-api/one-api | 服务端网关 | 一个 Key 调多模型 | 需自建服务器；客户端配置仍手动 |
| ASAR 补丁脚本群 | Python/Node 命令行 | 唯一解锁 Codex Desktop 方案族 | 纯命令行；每次更新重打；无配置管理 |

**关键调研事实**：Codex Desktop 与 Codex CLI 共用 `~/.codex/config.toml` + `auth.json`——纯配置写入对三目标全部生效，ASAR 补丁只是解锁高级 UI 能力的可选增量。MVP 风险大幅降低。

## 3. 市场空白

1. 多目标空白：所有现役切换器都不支持 WorkBuddy
2. GUI 化补丁空白：ASAR 补丁全是命令行脚本
3. 便携性空白：单文件免安装、U 盘即走无人做
4. Key 安全空白：无竞品遵守「不存储、不打包、仅透传写入目标官方路径」原则
5. 故障点空白：无工具走「零常驻、零代理」路线（cc-switch 差评最集中处）

## 4. 用户画像

| 画像 | 占比 | 特征 | 核心诉求 |
|------|------|------|----------|
| 多工具个人开发者 | 60% | 会复制粘贴命令但不想手改 TOML/JSON | 买完 Key 10 分钟内三工具全部能用 |
| 多机便携用户 | 25% | 公司机+个人机切换、重装频繁 | U 盘带一个 exe 走天下，公司电脑不留 Key |
| 技术分享者 | 15% | 教程作者、团队布道者 | 读者一键完成，界面可截图 |

## 6. 明确不做（Out of Scope）

1. 不做本地代理/请求转发/格式转换——零常驻是核心差异化
2. 不做用量统计/成本监控/Token 计数
3. 不做 MCP/Skills/Prompts 管理
4. 不做云同步/账号体系/云端 Key 托管
5. 不内置任何预设中转站或 Key——密钥强制手动录入，仅透传写入目标官方路径
6. 不修改 WorkBuddy 程序本体；除显式勾选的补丁外不触碰应用安装目录
7. 不做 Linux GUI
8. 不做工具本体自动更新（后续版本再说）

## 7. 验收标准（核心 8 条，Given/When/Then）

1. **AC-01** Given 已填有效端点和 Key，When 点击「测试连接」，Then 3 秒内返回成功（含延迟）或分类错误（Key 无效/端点不可达/网络超时），不写任何文件
2. **AC-02** Given 中转站返回 /v1/models，When 拉取完成，Then 呈现已过滤的可对话模型清单（非对话模型默认剔除且可勾回），0 结果显示空状态指引
3. **AC-03** Given 完成模型勾选，When 点击「写入」，Then 先展示 Diff 预览，确认后原子写入：任一文件失败全部回滚到写前状态
4. **AC-04** Given 任一目标配置文件不存在，When 写入，Then 自动创建目录与合法初始文件，不报错中断
5. **AC-05** Given 写入成功，When 点击「回滚」，Then 一键恢复最近备份并提示重启对应工具生效
6. **AC-06** Given 未勾选 ASAR 补丁，When 完成写入流程，Then 全程不触碰 Codex Desktop 安装目录（文件监控验证）
7. **AC-07** Given 勾选补丁并二次确认，When 补丁执行，Then 仅操作独立副本，失败时原文件保持原样并展示恢复指引
8. **AC-08** Given 离线环境，When 手动填写模型 ID 流程，Then 除「拉取模型」和「连通性测试」外全部功能可用
9. **AC-09** Given 用户拿到分发包，When 双击运行（Windows 双击 exe / macOS 双击 .app），Then 2 秒内出现 GUI 窗口且无需安装任何运行时依赖
10. **AC-10** Given 全新环境，When 用户粘贴 Key 与地址并点击「一键配置」，Then 除粘贴外全程 ≤1 次点击完成目标写入与验证；模型选择与 Diff 默认自动处理

## 8. 边界条件

- 空状态：无目标工具安装→检测引导；模型列表空→端点路径提示
- 错误状态：401/403/404/超时分别人话翻译+建议动作
- 加载状态：拉模型/测连接/写入均带进度与可取消
- 边界值：超长 Key 自动 trim；端点末尾多余 /v1、/chat/completions 自动纠偏提示
- 并发：单实例锁，禁止双开同时写入
- 权限：macOS 写 /Applications 需授权引导；Windows Program Files 写入失败降级提示
- 离线：见 AC-08

## 9. 非功能需求

| 类别 | 要求 | 优先级 |
|------|------|--------|
| 性能 | 启动 <1s；连通性测试 p95 <3s；模型拉取 p95 <3s | P0 |
| 可用性 | 零常驻进程；写入原子性（临时文件+重命名）；任一目标失败不污染其他目标 | P0 |
| 安全 | HTTPS 证书校验；Key 不落工具自身文件、日志脱敏 sk-****；写入前强制备份；补丁二次确认 | P0 |
| 兼容性 | Windows 10+ / macOS 12+；Electron 打包免安装（Windows portable exe / macOS .app zip），双击直接运行（ADR-007） | P0 |
| 图标 | 统一 SVG 图标库（锁定 Lucide，见架构文档 ADR-006） | P1 |
| 可访问性 | WCAG 2.1 AA 基本合规；全中文文案 | P2 |
| 遥测 | 默认完全无遥测；opt-in 匿名统计（不上报 IP/Key/端点） | P1 |
